# Reviewer guide

1. Sign in with an active reviewer account to open **Annotation reviews**.
   Administrators can open the same queue with **Annotation reviews** in the header.
2. Select **Review submission** beside a submitted assignment.
3. Read the submitted segment descriptions and whole-video summary. Use the video
   controls or **Play from ...** buttons to compare them with the media.
4. Choose **Approve annotation**, or enter a comment and choose **Return for changes**.
   A return comment is required so the annotator knows what to fix.
5. Return to the queue. After the annotator resubmits, open the submission again
   to review the revised content. Use **Refresh queue** to see recent changes.

Annotations are read-only to reviewers. The displayed text is a saved submission,
not the annotator's live draft. History lists submissions, returns, approvals and
comments with names and timestamps. You cannot review your own authored work.

If another reviewer has already acted, refresh the review before proceeding.
Approved work cannot currently be reopened. See [workflow details](../review-workflow.md).
