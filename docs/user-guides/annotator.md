# Annotator guide

1. Open an assigned video using **Start** or **Continue**.
2. Create segments, set their ranges, and save a video description and an audio
   description for each one. Save the whole-video summary too.
3. Choose **Submit for review** and confirm. Unsaved changes must be saved first.
   **Mark complete** only records your own progress; it does not submit work.
4. Submitted work is read-only. Refresh to check the status and any review feedback.
5. If work is returned, choose **Revise**, read the comment, save your changes and
   choose **Resubmit for review**. Earlier feedback remains in the review history.
6. Approved work stays read-only and is shown as **Approved** in your assignments.

Use **Skip for now** if you cannot finish a video yet; an optional reason is saved
in the history. Skipping keeps saved annotations. Choose **Resume** and save an
edit to continue the assignment. Skipping is unavailable while changes are unsaved
or the work is submitted/approved.

See [workflow details](../review-workflow.md) for states and validation rules.
